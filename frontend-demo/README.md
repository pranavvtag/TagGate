# TagGate Frontend Demo

Next.js App Router prototype for the TagGate SRS and supplied mobile screen designs.

## Run

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Notes

- Uses Next.js `16.2.6`, TypeScript, Tailwind CSS, and local mock data only.
- Desktop and mobile views are separate component trees selected by `DeviceView`.
- Original SRS and screenshots are stored in `docs/`.
